## 1 · LP FOUNDATIONS & MODELLING [L1–2]
**Workflow:** define variables + units → objective → every constraint → variable domains → check feasibility and units. LP is linear in **decision variables**; coefficients may be nonlinear functions of known data. E.g. a²x + √a y ≤ 1 is linear when a is a fixed parameter; xy and x² are not linear.
**LP assumptions:** proportionality, additivity, divisibility (fractions allowed), known coefficients. LP = continuous; IP = discrete; MIP = both; DP = sequential decisions with a sufficient state. Revenue p·x is linear only if p is fixed.
**Standard form used in class:** min cᵀx, Ax = b, x ≥ 0. Max cᵀx = −min(−cᵀx). Row “≤”: add slack +s; “≥”: subtract surplus −s; s ≥ 0. Free x = x⁺ − x⁻; x⁺,x⁻ ≥ 0. If x ≤ 0, substitute x = −u, u ≥ 0. Lower bound x ≥ ℓ: x = ℓ + u.
**Example:** min 2x + 3y, x − y ≥ 4, x free, y ≤ 0 becomes min 2x⁺ − 2x⁻ − 3u; x⁺ − x⁻ + u − s = 4; all new variables ≥ 0.
**Production/procurement:** quantities x, purchases y; max pᵀx − cᵀy; Ax ≤ y, cᵀy ≤ B, x,y ≥ 0. With nonnegative costs and no other purchase restrictions, eliminate y: max (pᵀ − cᵀA)x; cᵀAx ≤ B.
**Diet / staffing:** min cᵀx; nutrient bounds L ≤ Ax ≤ U. For shifts, A_tj = 1 if shift j covers period t; ∑ⱼ A_tj x_j ≥ demand_t. Pay **whole-shift** cost. Full-time ≥ part-time must hold separately each period.
**Absolute values:** |r| ≤ t ⇔ r ≤ t and −r ≤ t. Min ∑w_i|r_i| (w_i ≥ 0): min ∑w_i t_i, t_i ≥ ±r_i. Min max_i|r_i|: min t, t ≥ ±r_i ∀i. ∑|x_i| ≤ B: t_i ≥ ±x_i, ∑t_i ≤ B. This trick does **not** enforce t = |r| if objective/constraints do not push t down; |x| ≥ b is generally nonconvex.
**Example:** min 2x₁ + 3|x₂−10|, |x₁+2| + |x₂| ≤ 5 → min 2x₁+3t; t ≥ x₂−10, t ≥ 10−x₂; u ≥ ±(x₁+2), v ≥ ±x₂; u+v ≤ 5. Keep x₁,x₂ free.
**Regression/sparsity:** residual r_i = b_i−a_iᵀβ. L1 = sum absolute residuals (LP, less outlier-sensitive); L∞ = largest absolute residual (LP); L2 = sum squared residuals (quadratic). Sparse recovery: min ∑|x_j| s.t. Ax=b. For x₁+2x₂=2: L1 gives (0,1); L2 gives (0.4,0.8).
## 2 · GEOMETRY, BASIS & SIMPLEX [L2–3]
**Linear algebra:** A is m×n, Ax=b; (AB)ᵀ=BᵀAᵀ. Square A invertible ⇔ independent columns/rows ⇔ det A≠0. For A=[a b; c d], A⁻¹=[d −b; −c a]/(ad−bc). rank = number of independent columns = independent rows. Nonzero outer product uvᵀ has rank 1.
**Convex:** λx+(1−λ)y is feasible for λ∈[0,1]. Convex f: f(λx+(1−λ)y) ≤ λf(x)+(1−λ)f(y). Convex minimization: every local minimum is global. LP is convex; IP generally is not. Polyhedron = finite intersection of linear halfspaces/hyperplanes.
**BFS/extreme point:** n independent active constraints in n variables (include nonnegativity). For Ax=b, rank A=m: choose m independent columns B; set x_N=0; x_B=B⁻¹b. Feasible iff x_B≥0. At most m positive variables; a basic variable may be zero (**degenerate**). ≤ C(n,m) bases. Different bases may represent the same point.
**Examples:** x₁+x₂+x₃=1, x≥0 has BFS (1,0,0),(0,1,0),(0,0,1); (½,½,0) is not BFS. [0,1]³ has 8 vertices. Counting active rows alone fails if rows are dependent.
**LP outcomes:** finite optimum (unique or multiple), infeasible, unbounded objective. Unbounded feasible set need not mean unbounded optimum. A feasible standard-form LP with finite optimum has an optimal BFS. General polyhedra with lines need not have vertices.
**Simplex, MIN convention:** from a BFS choose entering nonbasic j. Set d_j=1, other nonbasic d=0, d_B=−B⁻¹A_j. Reduced cost r_j=c_j−c_BᵀB⁻¹A_j=cᵀd. If all r_j≥0, optimal. Otherwise enter r_j<0; θ*=min_{i:d_Bi<0} x_Bi/(−d_Bi). Update x←x+θ*d; minimizing-ratio basic variable leaves. No negative d_B entry ⇒ unbounded. For MAX, enter r_j>0; optimal when all r_j≤0.
**Worked pivots:** max x₁+x₂; x₁+2x₂+s₁=3, 2x₁+x₂+s₂=3. Start (0,0,3,3). Enter x₂: d=(0,1,−2,−1), θ=min(3/2,3)=1.5 → (0,1.5,0,1.5). Enter x₁: d=(1,−½,0,−1.5), θ=min(3,1)=1 → (1,1,0,0), z=2. For min −x₁−x₂, final slack reduced costs =⅓,⅓ ≥0.
**Pivot traps:** ratio test uses only decreasing basic variables. θ=0 means degeneracy, not infeasibility. Zero reduced cost permits another optimum if a positive feasible step exists. Adjacent bases exchange one column.
**Gurobi essentials (lecture code):** from gurobipy import *; m=Model(); x=m.addVars(n) (default x≥0, continuous); m.setObjective(quicksum(c[j]*x[j] for j in range(n)), GRB.MAXIMIZE); m.addConstr(...); m.optimize(). Solution: x[j].x, m.objVal. Use vtype=GRB.BINARY or GRB.INTEGER when needed; lb=-GRB.INFINITY for free variables. Check solver status before reading a solution.

## 3 · DUALITY & OPTIMALITY [L4]
**Two main pairs (A transposes):**
MAX cᵀx; Ax≤b, x≥0 ↔ MIN bᵀy; Aᵀy≥c, y≥0.
MIN cᵀx; Ax≥b, x≥0 ↔ MAX bᵀy; Aᵀy≤c, y≥0.
**Standard-form pair:** min cᵀx, Ax=b, x≥0 ↔ max bᵀy, Aᵀy≤c, y free. Primal rows ↔ dual variables; primal variables ↔ dual rows. A is m×n ⇒ dual has m variables and n constraints.
**Mixed-sign recipe, MAX primal:** primal row ≤ / ≥ / = gives y ≥0 / ≤0 / free. Primal variable x_j ≥0 / ≤0 / free gives dual row (Aᵀy)_j ≥c_j / ≤c_j / =c_j. For a **MIN primal**, reverse these inequality directions and y signs; equality/free stays unchanged.
**Mixed example:** max 3x₁+2x₂; x₁+x₂≤4, 2x₁−x₂=1; x₁≥0, x₂ free. Dual: min 4y₁+y₂; y₁+2y₂≥3, y₁−y₂=2; y₁≥0, y₂ free.
**Weak duality:** any feasible MAX-primal x and MIN-dual y satisfy cᵀx ≤ bᵀy. Thus a feasible dual is an upper bound and feasible primal a lower bound. Equal objectives certify both optimal. **Strong duality:** finite LP optimum ⇒ dual optimum exists with equal value. Unbounded primal ⇒ infeasible dual. Infeasible primal ⇒ dual may be infeasible OR unbounded; no converse shortcut.
**Complementary slackness, max/≤ pair:**
y_i[b_i−(Ax)_i]=0 ∀i; x_j[(Aᵀy)_j−c_j]=0 ∀j.
Together with primal + dual feasibility these certify optimality. Positive primal slack ⇒ y_i=0; y_i>0 ⇒ row binding. x_j>0 ⇒ dual row j tight. Binding does **not** imply positive y; y=0 does not imply slack.
**Solve dual from known primal:** identify slack primal rows → set corresponding y=0; for positive x_j solve A_jᵀy=c_j; then check all signs, remaining dual inequalities and equal objective.
**Wyndor anchor:** max 3x₁+5x₂; x₁≤4, 2x₂≤12, 3x₁+2x₂≤18, x≥0. Vertices/objectives: (0,0):0; (4,0):12; (4,3):27; (2,6):36; (0,6):30. Optimum x*=(2,6), slacks=(2,0,0).
**Wyndor dual:** min 4y₁+12y₂+18y₃; y₁+3y₃≥3, 2y₂+2y₃≥5, y≥0. Slack row 1 ⇒ y₁=0; x₁,x₂>0 ⇒ 3y₃=3, 2y₂+2y₃=5. Hence y*=(0,1.5,1); dual value 36 = primal value.
**Economic meaning:** y_i = marginal objective value of one more unit of resource i, locally. A_jᵀy = opportunity cost of resources for product j. At optimum, produced products earn exactly this resource value; unproduced products cannot exceed it at an optimal dual price.
**Lagrangian:** for min cᵀx, Ax=b, x≥0, L=cᵀx+yᵀ(b−Ax). g(y)=inf_{x≥0}L is bᵀy if Aᵀy≤c, otherwise −∞. Maximize g to get strongest lower bound. For nonlinear problems strong duality need not hold.
**Example:** min x²+y², x+y=1. L=x²+y²+p(1−x−y); minimizing gives x=y=p/2, g(p)=p−p²/2. Max at p=1: g=½, x=y=½. Any p gives a lower bound.
## 4 · SENSITIVITY / WHAT-IF [L4]
**With same optimal basis B:** x_B=B⁻¹b; dual yᵀ=c_BᵀB⁻¹; r_N=c_N−A_Nᵀy. RHS changes: x_B(new)=B⁻¹(b+Δb); maintain x_B(new)≥0. Objective changes: recompute y and r_N; MIN needs r_N≥0 (MAX ≤0).
**RHS value:** z(new)=z*+yᵀΔb while basis stays optimal. **Objective-coefficient change:** z(new)=z*+Δcᵀx* while x* remains optimal. Sensitivity ranges are normally **one change at a time**; simultaneous changes require joint basis checks. A boundary can create degeneracy/alternative optima.
**Wyndor resource 3:** b₃=18+δ ⇒ x₂=6, x₁=2+δ/3, s₁=2−δ/3. Feasible for −6≤δ≤6; z=36+δ. +3 hours ⇒ z=39. +9 hours exceeds range: optimum (4,6), z=42, **not 45**.
**Other RHS ranges:** varying b₁ alone: b₁≥2 (no upper limit), z=36. Varying b₂ alone: 6≤b₂≤18, x₂=b₂/2, x₁=(18−b₂)/3, z=18+1.5b₂.
**Wyndor profit change:** hold c₂=5. y₃=c₁/3, y₂=2.5−c₁/3; y≥0 iff 0≤c₁≤7.5. Then (2,6) stays optimal, z=2c₁+30. c₁=4 ⇒ z=38; c₁=10 ⇒ new optimum (4,3), z=55. Hold c₁=3: same basis for c₂≥2.
**New constraint (MAX):** optimum cannot rise. If old optimum satisfies it, value is unchanged. Example x₁+x₂≤10: (2,6) still feasible ⇒ z=36. A nonbinding constraint need not be globally redundant.
**New nonnegative variable (MAX):** optimum cannot fall because new variable can be 0. Compute r_new=c_new−yᵀa_new. If r_new≤0, old dual stays feasible ⇒ old optimum remains. If >0, old dual fails; reoptimize (degeneracy may prevent strict improvement). Wyndor a=(2,4,6), c=6 ⇒ r=6−12=−6: no gain.
**Buying capacity:** compare extra profit with extra cost **within range**. Wyndor plant 3 offers 3 hours at 0.7 per hour: net gain=3(1−0.7)=0.9 (objective units). Shadow prices are not valid indefinitely.
**Bound intuition:** adding constraints shrinks feasible set: MAX ↓ / MIN ↑; relaxing constraints or adding optional variables: MAX ↑ / MIN ↓. For MAX, old x* gives a lower bound after a coefficient change; old feasible dual gives an upper bound after an RHS change.

## 5 · LP CASES & UNCERTAINTY [L5]
**Markdown LP:** price levels p_k, demand/week d_k, effective weeks t_k≥0, initial stock Q, horizon H, salvage s. Max sQ+∑ₖ(p_k−s)d_k t_k; ∑d_k t_k≤Q; ∑t_k≤H; t_full≥1. Purchase cost is sunk. Order used levels high→low for no price increase. Fractional weeks allowed; model assumes time-independent demand rates.
**Lecture example:** Q=2000, H=15, s=25; (p,d)=(60,125),(54,162.5),(48,217.5),(36,348.8). Optimum t=(11⅔,3⅓,0,0). Check: 125(11⅔)+162.5(3⅓)=2000; revenue=60(1458⅓)+54(541⅔)=116750. At least 3 full-price weeks changes nothing. After poor sales: update **remaining** stock/time and solve again; past sales are fixed.
**Sensitivity vs uncertainty:** sensitivity changes known data and resolves; uncertainty chooses some actions **before** unknown data is observed. Nominal = optimize forecast/mean; robust = feasible for every realization in a specified set; stochastic = optimize expected outcome with probabilities/recourse.
**Drug sourcing case:** output x, raw purchases q₁,q₂≥0. Max 5500x−100q₁−199.9q₂; 90x≤2000, 40x≤800, q₁+q₂≤1000, 700x+100q₁+199.9q₂≤100000. Ingredient: .01q₁+.02q₂≥.5x.
**Box robustness:** raw content a₁∈[.00995,.01005], a₂∈[.0196,.0204]. Since q≥0, robust ingredient row uses **lowest** yields: .00995q₁+.0196q₂≥.5x. Nominal plan ≈(x,q₁,q₂)=(17.55,0,438.79), profit 8819.66; may violate realized yield. Robust plan ≈(17.47,877.73,0), profit 8294.57. Worst-case lower yield can change preferred supplier.
**Worst-case direction:** for ∑a_jx_j≤b with x≥0, choose largest a and smallest b; for ≥ choose smallest a and largest b. With signed x use bounds/absolute values; cannot blindly pick one endpoint.
**Budgeted uncertainty:** a_j=ā_j+â_j z_j, |z_j|≤1, ∑|z_j|≤Γ. Lecture Γ=2α, 0≤α≤1: α=0 nominal; α=1 full box. Larger Γ ⇒ more protection, smaller robust feasible set.
**Compact robust LP (q≥0):** require min_z ∑(ā_j+â_j z_j)q_j ≥ R. Equivalent: ∑ā_jq_j−Γρ−∑s_j≥R; ρ+s_j≥â_jq_j; ρ,s_j≥0. This uses duality for the worst-case loss max∑â_jq_j u_j, ∑u_j≤Γ, 0≤u_j≤1. Drug: ā=(.01,.02), â=(.00005,.0004), R=.5x.
**Small example:** q=(100,100), nominal ingredient=3; losses=(.005,.04). Γ=0 ⇒ 3; Γ=1 ⇒ 3−max(.005,.04)=2.96; Γ=2 ⇒ 2.955. For fractional Γ, sort losses and take full largest losses plus the fraction of the next.
## 6 · SCENARIOS & RECOURSE [L6–7]
**Two-stage flexibility:** build links y_ij∈{0,1} before demand; allocate x_ij(D) afterward. Max −∑K_ij y_ij+E[Q(y,D)]; Q=max∑p_j x_ij, with ∑ⱼx_ij≤C_i, ∑ᵢx_ij≤D_j, 0≤x_ij≤M_ij y_ij. Use a valid tight M, e.g. C_i.
**Sample average approximation (SAA):** K sampled demands D^k; one common y, separate x^k. Max −∑K_ij y_ij+(1/K)∑ₖᵢⱼp_jx_ij^k, with capacity, demand and link constraints **for each k**. For unequal probabilities use ∑p_kQ_k. Do not average demands first; E[min(C,D)] ≠ min(C,E[D]). Do not give first-stage y a scenario index: that assumes future knowledge.
**Mini-example:** capacity 1; D=0 or 2, each with probability ½. Expected optimal sales E[min(1,D)]=½. Using average demand E[D]=1 predicts sales 1 and overstates performance.
**Fixed-design simulation:** sample D, solve allocation LP, average optimal sales/profit. Lecture D_j=max(X_j,0), X_j normal: clipping at zero is not conditional resampling. Use the same demand samples to compare designs; increase sample size until the difference stabilizes.
**Inventory/transshipment:** first-stage stock q_i, per-scenario shipments f_ij^k≥0 (include i=j for local sales). ∑ⱼf_ij^k≤q_i; ∑ᵢf_ij^k≤D_j^k. Max −c∑q_i+(1/K)∑ₖᵢⱼ(p−t_ij)f_ij^k. Subtract a service fixed cost once if paid regardless of use; an already paid cost does not affect future decisions.
## QUICK MODELLING / EXAM CHECKS
**Recognize patterns:** “at least” ≥; “at most” ≤; “exactly” =. Capacity constrains **total usage**; demand constrains **total delivery**. Index each constraint by what it protects. Percentages: 0.005%=0.00005, not 0.005.
**Profit vs revenue:** subtract variable purchase/production costs; ignore sunk costs when comparing future actions. “No sale” is feasible only if minimum demand/commitment constraints allow it. Add variable upper bounds when physically required.
**Portfolio example:** max∑r_ix_i; ∑x_i≤B, x≥0. Put all budget in a highest positive-return stock; if all r_i≤0, investing nothing is optimal. Dual min By, y≥r_i, y≥0 ⇒ y*=max(0,max r_i). Tied best stocks permit split optima.
**Useful checks:** plug your answer into every row; calculate slacks; check signs and units; prove optimum using primal=dual value, reduced costs, a matching bound, or a Bellman comparison. Feasible ≠ optimal; binding ≠ valuable; an LP fractional optimum need not round to an IP optimum.
**Lecture map:** L1 OR/model choice; L2 LP + reformulation; L3 BFS/simplex; L4 duality/sensitivity; L5 markdown/robustness; L6 networks; L7 IP/relaxation/B&B; L8 DP. Examples marked “lecture” use course data; other small examples are added for practice.

## 7 · NETWORK FLOW [L6]
**Graph facts:** G=(N,A); directed arcs are ordered. Tree = connected, acyclic undirected graph; spanning tree uses all n nodes and n−1 edges. Complete undirected graph: n(n−1)/2 edges; directed (no loops): n(n−1). Bipartite: edges only between two sets; complete bipartite m×n edges. Every tree is bipartite; not conversely.
**Min-cost flow:** min ∑_(i,j) c_ij f_ij; ∑ⱼ f_ij−∑ⱼ f_ji=b_i ∀i; ℓ_ij≤f_ij≤u_ij. **Out−in=b:** supply b>0, demand b<0, transit b=0; ∑b_i=0 necessary (not sufficient). Arc column has +1 at origin, −1 at destination. One balance row is redundant in a connected network; incidence rank n−1.
**Lower bounds:** set f=ℓ+g; new capacity u−ℓ; new supply b′_i=b_i−∑ⱼℓ_ij+∑ⱼℓ_ji. A required shipment d can be fixed by ℓ=u=d. Prohibited arcs: omit or set u=0.
**Transportation:** min∑c_ijx_ij; ∑ⱼx_ij=a_i (supplies), ∑ᵢx_ij=d_j (demands), x≥0. Balanced iff ∑a=∑d; add a dummy for legitimate unused supply/unmet demand, using appropriate cost/penalty. Connected m+n-node transportation basis: m+n−1 tree arcs (some may have zero flow).
**Tree example (assignment):** supplies a,100−a; demands 70,30; set x₁₁=0. Balances give x₁₂=a, x₂₁=70, x₂₂=30−a. Feasible iff 0≤a≤30. At a=30, tree variable x₂₂=0: degenerate BFS. A spanning tree gives a basic solution; check nonnegativity for BFS.
**Initial transport solution:** northwest-corner allocates min(remaining supply,demand), removes exhausted row/column; least-cost method uses cheapest available cell. Both can need zero basic arcs in ties. Neither guarantees optimality.
**Transport pivot:** for basic arcs solve u_i+v_j=c_ij (fix one potential=0). Nonbasic reduced cost r_ij=c_ij−u_i−v_j; MIN optimal if all r≥0. Enter a negative-r arc, form unique tree cycle, alternate +/−, send θ=min flow on “−” arcs; one such arc leaves.
**2×2 pivot:** costs [2,5;4,1], supplies (3,2), demands (2,3). Start x₁₂=3,x₂₁=2 (cost 23), add zero basic x₂₂. Enter x₁₁: cycle +11,−12,+22,−21. θ=2 → (x₁₁,x₁₂,x₂₁,x₂₂)=(2,1,0,2), cost 11; per-unit change 2−5+1−4=−6.
**Assignment:** x_ij≥0, each row sum=1, each column sum=1; min∑c_ijx_ij. Integral optimum exists; explicit binaries unnecessary for pure assignment. Forbidden pairs remove arcs; unequal set sizes may need dummies. Greedy can fail: costs [2,3;10,20], greedy 2+20=22, optimum 3+10=13.
**Shortest path as flow:** send 1 unit, b_s=1,b_t=−1, others 0; min∑c_ijf_ij. With nonnegative costs an optimal simple path exists. Negative cycles can spoil this formulation. Reliable path with independent arc success p_ij: maximize product p ⇔ minimize ∑−log p.
**Maximum flow:** max F; out−in=F at source, −F at sink, 0 elsewhere; 0≤f≤u. Or add t→s arc with cost −1 and minimize circulation cost. Any s–t cut capacity bounds flow; max flow=min cut. Residual forward capacity=u−f, reverse=f; augment along residual paths, including reverse arcs to undo earlier choices.
**Time-expanded network:** node=(location,time). Travel arcs move to arrival time; holdover arcs keep inventory at a location. Flow conservation carries stock between periods; required deliveries are lower bounds/fixed flows. Never let a departure use inventory that arrives later.
**Process flexibility:** source→plant capacity C_i; plant→product only if capable; product→sink capacity D_j. Max flow=maximum sales. Dedicated sales=∑min(C_i,D_i); full flexibility=min(∑C_i,∑D_j). Example capacities (100,100,100), demand (20,140,140): dedicated 220, full 300.
**Project / crashing:** activity start s_i, duration d_i, reduction r_i∈[0,R_i]. Precedence i→j: s_j≥s_i+d_i−r_i. Min∑k_ir_i; finish≤deadline; s≥0. Earliest finish is longest-path length; critical path has zero slack. Example A(3)→C(4), B(2)→C: duration 7; crashing B alone cannot reduce 7. Multiple critical paths may need simultaneous reductions.
## 8 · INTEGRALITY & BOUNDS [L7]
**TU:** every square subdeterminant is 0,+1,−1. With integer RHS/bounds, a TU constraint system has integral BFS. Directed incidence and bipartite assignment matrices are TU. Cramer: x_Bi=det(B with col i replaced by b)/det B. Integer b and det B=±1 ⇒ integer x_B. Merely having entries 0,±1 is insufficient: [1 1;1 −1] has det −2. Extra side constraints can destroy integrality.
**LP relaxation:** drop integrality, retain 0≤x≤1 for binaries. MAX: incumbent≤IP optimum≤LP bound. MIN: LP bound≤IP optimum≤incumbent. Integral LP optimum solves IP; fractional LP may round infeasibly or suboptimally.
**Branch & bound:** solve node LP; prune if infeasible, integer optimum, or bound no better than incumbent. Fractional x_j=v: branch x_j≤⌊v⌋ and x_j≥⌈v⌉. MAX global upper bound=max bounds of live nodes (and incumbent); MIN global lower bound=min. Stop when no node can improve incumbent.
**Lecture B&B:** max 1000x₁+950x₂+350x₃, 100x₁+80x₂+50x₃≤200, binaries. Root LP=(1,1,.4), UB=2090. x₃=0 ⇒ (1,1,0), incumbent=1950. x₃=1 ⇒ (.7,1,1), UB=2000; branch x₁: 0 gives 1300; 1 gives (1,.625,1), UB=1943.75. Both prune ⇒ optimum 1950.

## 9 · INTEGER MODELLING TOOLKIT [L7]
**Binary logic (all variables 0/1):** at most k: ∑x≤k; at least k: ∑x≥k; exactly k: ∑x=k. A⇒B: a≤b. A⇒not B: a+b≤1. Not A⇒B: a+b≥1. A iff B: a=b. A⇒(B AND C): a≤b,a≤c. A⇒(B OR C): a≤b+c. (A AND B)⇒C: a+b−1≤c.
**Exact AND:** z=ab ⇔ z≤a,z≤b,z≥a+b−1. For n variables: z≤x_i ∀i, z≥∑x_i−n+1. **Exact OR:** z≥x_i ∀i, z≤∑x_i. Implication alone needs only its direction: “if any x=1 then z=1” needs z≥x_i; “if all x=0 then z=0” needs z≤∑x_i.
**Threshold:** if ∑x_i≥k then z=1: ∑x_i≤(k−1)+(n−k+1)z (1≤k≤n). For “iff”, also ∑x_i≥kz. Example n=8,k=5: ∑x≤4+4z; if sum=5, z=0 is impossible.
**On/off:** 0≤q≤Uy means no production when y=0. If production is either 0 or at least L: Ly≤q≤Uy. Fixed cost: objective K y+cq. q≤Uy alone does not force y=0 when q=0; a positive fixed cost does so at optimum if no other constraint forces y=1.
**Binary×continuous:** z=yq, y binary, 0≤q≤U: 0≤z≤Uy; z≤q; z≥q−U(1−y). Example q=7,U=10: y=0 forces z=0; y=1 forces z=7. Do not put yq directly in an MILP.
**Conditional rows:** y=1⇒aᵀx≤b: aᵀx≤b+M(1−y). y=1⇒aᵀx≥b: aᵀx≥b−M(1−y). Equality needs both. “Either aᵀx≤b OR cᵀx≤d”: first ≤b+My, second ≤d+M(1−y). Choose M from valid bounds, as small as possible; test y=0 and y=1.
**Knapsack:** max∑v_ix_i; ∑w_ix_i≤W; x binary. Value/weight greedy solves fractional knapsack, not generally 0–1. Lecture counterexample: values (1000,950), weights (100,80), W=100. LP=(.2,1), z=1150; round to (0,1), z=950; IP optimum (1,0), z=1000.
**Facility location:** open y_i binary, shipments q_ij≥0; min∑F_iy_i+∑c_ijq_ij. Demand ∑ᵢq_ij=d_j; link q_ij≤d_j y_i; capacity ∑ⱼq_ij≤C_iy_i if capacitated. Uncapacitated aggregate bound ∑ⱼq_ij≤(∑d_j)y_i. Without a linking constraint, a closed facility can ship for free.
**Lot sizing:** end inventory I_t=I_(t−1)+q_t−d_t; I_t≥0 (no backlog), I₀ fixed; 0≤q_t≤M_t y_t, y_t binary. Min∑(K_ty_t+c_tq_t+h_tI_t). Set terminal inventory if specified; M_t=∑_{τ=t}^T d_τ is valid when excess production is unnecessary. Airplane example: d=(3,2,3,2), K=2, h=.2; q=(10,0,0,0), I=(7,5,2,0), total=2+.2(14)=4.8 million.
## 10 · ROUTING, PRICING & SCHEDULING
**Directed TSP:** x_ij binary, i≠j; min∑c_ijx_ij. One outgoing ∑_{j≠i}x_ij=1 and one incoming ∑_{i≠j}x_ij=1. These alone form a **cycle cover**, not necessarily a tour; assignment optimum is a lower bound for min TSP.
**DFJ subtour cuts:** ∑_{i,j∈S,i≠j}x_ij≤|S|−1 for all proper S⊂N with 2≤|S|≤n−1. Example subtour 2→3→2 violates x₂₃+x₃₂≤1. Equivalently, every proper nonempty subset has ≥1 outgoing arc. Many constraints; can add violated cuts iteratively.
**MTZ alternative:** depot=1; 1≤u_i≤n−1 for i=2,…,n; u_j≥u_i+1−(n−1)(1−x_ij), i≠j, i,j≥2. u_i records visit order. Exclude depot from these comparisons so return is possible; u can be continuous. Summing selected order constraints around a customer-only cycle gives 0≥cycle length, impossible.
**Pickup before drop:** u_drop≥u_pick+1. Open route: allow free artificial return to start (cost 0), or use a separate terminal node. Forbid unavailable arcs instead of using literal infinity as a solver coefficient.
**Arrival-time formulation:** start t₁=0; t_j≥t_i+service_i+travel_ij−M_ij(1−x_ij) for j≠1. Windows a_j≤t_j≤b_j. M_ij≥b_i+service_i+travel_ij−a_j (use valid depot bounds). No time-propagation row back to fixed t₁; use a separate return-time variable if needed. Positive travel times eliminate customer subtours; zero-time cycles may still need cuts.
**Mini time example:** t₁=0, travel₁₂=3, travel₂₃=4. Selected 1→2→3 implies t₂≥3,t₃≥7. Deadline b₃=6 rules it out. **Total route time** ∑c_ijx_ij differs from **total customer waiting** ∑_{j≠1}t_j; choose the requested objective.
**Job shop:** operation start s_ik≥0; within-job order k→ℓ: s_iℓ≥s_ik+p_ik. Shared machine k for jobs i,j; y=1 means i before j: s_jk≥s_ik+p_ik−M(1−y); s_ik≥s_jk+p_jk−My. Completion C_i≥s_ik+p_ik ∀k. Min∑C_i for total completion/waiting (fixed release times and processing durations); min C_max with C_max≥C_i for makespan. These objectives are different.
**Tiny schedule:** same machine, durations A=2,B=3, both released at 0. A→B: completion (2,5), sum 7; B→A: (5,3), sum 8. Makespan 5 in both. Precedence alone does not prevent two jobs sharing a machine at once.
**Multiproduct price grid:** price p_m; x_nm=1 iff product n uses m. Demand D(n,m,k) depends on own price and **total** price k. For each possible fixed k, max∑p_mD(n,m,k)x_nm; ∑ₘx_nm=1 ∀n; ∑ₙₘp_mx_nm=k. Solve all k; choose highest value. Equally spaced M prices, N products ⇒ N(M−1)+1 totals vs M^N price vectors.
**Sudoku:** x_ijk=1 iff cell (i,j) contains digit k. Exactly one digit/cell; each digit once in each row, column and 3×3 block; fix clues x_ij,given=1. Feasibility objective min 0.

## 11 · DYNAMIC PROGRAMMING [L8]
**Five things to write:** stage, state, feasible action, transition, one-stage cost/reward; then value function, boundary and Bellman equation. State must retain all past information needed for future decisions; policy maps (stage,state) to action. Save subproblem values instead of recomputing. Store argmin/argmax to reconstruct decisions.
**Convention here:** t=number of periods **remaining** (matches lecture). Deterministic min-cost: V_t(s)=min_{a∈A_t(s)}{c_t(s,a)+V_(t−1)(f_t(s,a))}; V₀(s)=terminal cost. Reward maximization: replace min/cost by max/reward. Infeasible states get +∞ for min, −∞ for max; do not give them value 0.
**Principle of optimality:** after a chosen action, remaining actions must be optimal for the reached state. Compute backward from boundary; follow policy forward. DP works when subproblems share sufficient states; large state spaces cause the curse of dimensionality. Fibonacci memoization/tabulation takes O(n), unlike repeated recursion.
**Shortest path on staged DAG:** V₀(destination)=0; V_k(i)=min_{j:(i,j)∈A}[c_ij+V_(k−1)(j)]. Unreachable states +∞. At each state compare complete “edge cost + future value”, not just shortest outgoing edge.
**Lecture path example:** V(H)=23,V(I)=29. V(E)=min(16+23,18+29)=39; V(F)=min(18+23,11+29)=40; V(G)=min(15+23,13+29)=38. V(B)=55,V(C)=56,V(D)=59. V(A)=min(22+55,19+56,15+59)=74. Optimal route A→D→F→I→J: 15+19+11+29=74.
**0–1 knapsack DP:** F(i,b)=best value using first i items with budget b. F(0,b)=0 (b≥0). If w_i≤b: F(i,b)=max{F(i−1,b),v_i+F(i−1,b−w_i)}; else F(i,b)=F(i−1,b). Take vs skip; no fractional item. O(nW) with integer weights/budget (pseudo-polynomial). For 1D memory update b **downward** to avoid reusing an item.
**Lecture knapsack:** w=(2,3,4,6), v=(8,12,15,19), W=10. After items 1–3, best at budget 10 is 35 (items 1+2+3, weight 9). Compare item 4: 19+F(3,4)=19+15=34 ⇒ skip. Optimum 35, unused budget 1. Full budget need not be used.
**Small DP cells:** F(2,5)=max(F(1,5)=8,12+F(1,2)=20)=20. F(3,6)=max(20,15+F(2,2)=23)=23. Backtrack: if “take” wins, subtract item weight and move to previous item.
## 12 · STOCHASTIC DP & INFORMATION
**Bellman:** V_t(s)=min_{a∈A_t(s)} E_D[c_t(s,a,D)+V_(t−1)(f_t(s,a,D))]. Choose action before D realizes; average over D, then optimize over actions. Do not replace E[V(next state)] by V(E[next state]). For demand-dependent feasible actions, respect what is known when choosing.
**Order matters:** E[min_a cost(a,D)] ≤ min_a E[cost(a,D)]; the left allows knowing D before choosing a (perfect information), so is too optimistic for a pre-demand decision. For rewards, inequality reverses. Adaptive policies use only observations already available.
**Inventory recurrence (lost sales):** state s=stock before ordering, order q≥0, sales=min(s+q,D), next stock=(s+q−D)⁺. V_t(s)=min_q{cq+E[−p·min(s+q,D)+h(s+q−D)⁺+V_(t−1)((s+q−D)⁺)]}. If salvage v/unit: V₀(s)=−vs. If no salvage: V₀(s)=0. Specify order/storage limits if present.
**Lecture newsvendor:** c=.4,p=1; independent daily D∈{0,1} equally likely; zero holding/salvage; inventory carries over. One day: V₁(0)=min(0,.4−.5)=−.1 (order 1); V₁(1)=V₁(2)=−.5 (order 0). Existing stock is already paid for.
**Two-day decision from stock 0:** q=0: 0+V₁(0)=−.1. q=1: .4−.5+½V₁(0)+½V₁(1)=.4−.5−.05−.25=−.4. q=2: .8−.5+V₁(1)=−.2. Choose q₁=1, expected profit .4.
**Policy:** day 2 order 1 if no stock remains (D₁=1); order 0 if stock remains (D₁=0). Expected sales=1, expected purchases=1.5 ⇒ profit 1−.4(1.5)=.4. Best open-loop fixed orders (1,0): one unit sells with probability ¾ ⇒ profit .75−.4=.35. Value of adaptation=.05. Open-loop commits all actions beforehand; feedback uses observed state.
**Optional single-period shortcut:** price p, cost c, salvage v with p>c>v: order a demand quantile at critical ratio (p−c)/(p−v). Discrete demand: smallest q with F_D(q) at least this ratio. In lecture example ratio=.6; F(0)=.5<.6, F(1)=1 ⇒ q*=1.
## 13 · OPTIMAL STOPPING: SECRETARY
**Assumptions:** n candidates in uniformly random order, only relative ranks observed, accept/reject immediately, no recall; objective probability of selecting overall best. Any fixed interview position succeeds with probability 1/n.
**State r:** current candidate is a record/best-so-far (r=1) or not (r=0); index k also matters. Let W_k(r) be best success probability at candidate k. Boundary W_n(0)=0,W_n(1)=1. Reject/continue value R_k=[W_(k+1)(1)+kW_(k+1)(0)]/(k+1). Thus W_k(0)=R_k; W_k(1)=max{k/n,R_k}. Accepting a non-record has success 0; accepting a record succeeds with probability k/n.
**Worked n=4:** k=4: (W₄(0),W₄(1))=(0,1). k=3: R₃=¼; W₃=(¼,¾). k=2: R₂=(¾+2×¼)/3=5/12; W₂=(5/12,½). k=1: R₁=(½+5/12)/2=11/24; W₁(1)=11/24>¼, so reject candidate 1. Then accept first record among candidates 2–4; success 11/24≈45.8% vs fixed-position 25%.
**Large n rule:** observe/reject about n/e≈.368n candidates, then accept first later record. If none appears, selecting the last candidate cannot recover success. Threshold policy exploits information; it does not guarantee choosing the best.
**Final recall:** MIN simplex r≥0; MAX simplex r≤0. MAX primal ≤ ↔ MIN dual ≥. Network out−in=supply. MAX LP bound is upper; MIN LP bound is lower. DP needs boundary + feasible actions + transitions + expectation timing. Always give a numerical check with your model.
